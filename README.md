## Features
- Mipmapping (4 different levels)
- Optional debug view

## Usage
Mipmapping settings can be changed in the settings under ModMenu. Everything is off by default.

## Requirements
[StationAPI](https://github.com/ModificationStation/StationAPI) <br/>
[GCAPI](https://modrinth.com/mod/glass-config-api) <br/>
[ModMenu](https://github.com/calmilamsy/ModMenu)
